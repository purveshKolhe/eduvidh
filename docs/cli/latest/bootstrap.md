# `modal bootstrap`

Initialize a sample Modal App.

**Usage**:

```
modal bootstrap [OPTIONS] [NAME]
```

**Options**:

* `-o, --output TEXT`: Location for storing the template.
* `--force`: Overwrite the output directory if it already exists.
* `--help`: Show this message and exit.
